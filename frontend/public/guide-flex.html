i ใช้ตัวแปรอย่างไร

  • เลือกตัวแปรจากตารางด้านล่าง แล้วคลิกที่แท็กเพื่อคัดลอก จากนั้นนำไปวางในช่อง text หรือ url ของ image ในการ์ด
  • ตอนบอทตอบลูกค้า ระบบจะ แทนค่าจริง ของลูกค้าคนนั้นให้อัตโนมัติ เช่น {{profile.phone}} → เบอร์โทรจริง
  • ตัวแปรที่ลูกค้าไม่มีข้อมูล จะกลายเป็น - (ขีดเดียว) — การ์ดยังส่งได้ ไม่พังทั้งใบ
  • {{content}} = ข้อความที่บอทกำลังจะตอบ — ใช้ได้เฉพาะการ์ดชนิด profile
  • ออกแบบหน้าตาการ์ดให้เสร็จก่อน ใน LINE Flex Simulator ↗ แล้วค่อยนำแท็กมาวางแทนค่าคงที่

⛔ ใช้ค่าจากตัวแปร (var) เท่านั้น

ค่าที่เป็นข้อมูลของลูกค้า ต้องมาจากตัวแปรในตารางนี้เท่านั้น — ห้ามพิมพ์ค่าจริงลงไปเอง (เดี๋ยวทุกคนได้ค่าเดียวกันหมด)

แต่ ข้อความทั่วไปพิมพ์ปนได้ เช่น ชื่อหัวข้อ / ป้ายกำกับ — วางคู่กับตัวแปรได้เลย:

✔ ถูก: ☎ เบอร์โทร : {{profile.phone}}   ✘ ผิด: ☎ เบอร์โทร : 0955550010

⚠️ เช็คชื่อตัวแปรว่ามีจริง ในตารางเสมอ — พิมพ์ผิดจะโชว์เป็นตัวอักษรดิบ {{ชื่อผิด}}

! ข้อจำกัด

  • รูปใน image ต้องเป็น https:// เท่านั้น (http ธรรมดา LINE ตีกลับ)
  • url รูปยาว ไม่เกิน 2000 ตัวอักษร · url เสีย/ว่าง → ระบบสลับเป็นภาพสำรองให้อัตโนมัติ
  • ค่าว่าง = - แต่ เลข 0 จะออกเป็น "0" (ยอด 0 บาทคือข้อมูลจริง ไม่ใช่ว่าง)
  • รายการแบบ list (ฝาก/ถอน/สินค้า/เหรียญ) มีสูงสุด 10 รายการ — _1_ คือล่าสุด
  • ช่อง text ห้ามว่าง เด็ดขาด — LINE ตีกลับทั้งการ์ดถ้ามี text ว่าง
  • แท็กที่พิมพ์ผิด/ไม่มีในลิสต์นี้ จะโชว์เป็นตัวอักษรดิบ {{ชื่อผิด}}

# รูปแบบชื่อแท็ก (namespace)

แท็กจะขึ้นต้นด้วย ชื่อแหล่งข้อมูล เสมอ (ยกเว้นตัวแปรบริบท) — คลิกคัดลอกจากตารางได้ตัวเต็มที่ถูกต้องอยู่แล้ว

โปรไฟล์ลูกค้า{{profile.ชื่อตัวแปร}}
เช่น {{profile.phone}}
กติกาเว็บ{{site_rules.ชื่อตัวแปร}}
เช่น {{site_rules.dep_min}}
ตัวแปรบริบท (ของ hook){{ชื่อตัวแปร}} ไม่มี prefix
เช่น {{hook_domain}}

📌 ใช้แท็กแบบเต็มที่มี namespace เสมอ (เช่น {{profile.phone}}) — คลิกคัดลอกจากตารางได้ตัวที่ถูกต้อง

{} ตัวอย่างการใส่ตัวแปรจริง

โครง Flex บางส่วน — สังเกตว่า {{...}} อยู่ในค่าของ text และ url

// การ์ดโปรไฟล์ — text + รูปโปรโมชัน (สังเกต prefix profile. / site_rules.)
{
  "type": "bubble",
  "hero": { "type": "image",
    "url": "{{profile.promo_img}}",       // รูปแบนเนอร์โปร (เสีย→ภาพสำรอง)
    "size": "full", "aspectRatio": "20:13" },
  "body": { "type": "box", "layout": "vertical", "contents": [
    { "type": "text", "text": "สวัสดีคุณ {{profile.bank_account_name}}", "weight": "bold" },
    { "type": "text", "text": "ระดับ {{profile.tier_name}} · ยอดเครดิต {{profile.balance_credit}} บาท" },
    { "type": "text", "text": "☎ เบอร์โทร : {{profile.phone}}" },   // ข้อความทั่วไป (☎ เบอร์โทร :) + ตัวแปร ปนกันได้
    { "type": "text", "text": "ฝากขั้นต่ำ {{site_rules.dep_min}} บาท · {{content}}", "wrap": true }
  ] }
}

💡 ข้อความทั่วไปพิมพ์ปนกับตัวแปรได้ เช่น ☎ เบอร์โทร : {{profile.phone}} — ระบบแทนเฉพาะส่วน {{profile.phone}} ที่เหลือคงเดิม · แต่ต้องเช็คก่อนว่าชื่อตัวแปรมีจริงในตาราง

✓ ตรวจ JSON บน LINE Flex Simulator ก่อน (บังคับ)

ต้องออกแบบและทดสอบว่า JSON ใช้ได้จริงบน LINE Flex Simulator เท่านั้น — ก่อนนำเข้าระบบ

  1. เปิด LINE Flex Simulator ↗ แล้วกดปุ่ม </> View as JSON (มุมขวาบน)
  2. วาง JSON ของการ์ดลงในกล่อง แล้วกด Apply
  3. ถ้า ไม่ error และ แสดงผลถูกต้อง บน Simulator = นำเข้าใช้กับระบบได้
  4. ถ้า error หรือแสดงผลเพี้ยน → แก้ JSON ให้ valid ก่อน อย่าเพิ่งนำเข้าระบบ

▶ สร้าง Flex Message ในระบบ (หลังออกแบบเสร็จ)

เข้าสู่ระบบ (login) ก่อน แล้วทำตามขั้นตอน:

  1. เมนู จัดการทั่วไป → จัดการ Flex Message → กด สร้าง / เพิ่ม
  2. ตั้ง ชื่อ Flex เป็น ภาษาอังกฤษ · ห้ามเว้นว่าง
  3. เลือกรูปแบบ ปรับแต่ง (custom)
  4. วาง JSON ที่ออกแบบไว้ ลงในช่อง เนื้อหา JSON
  5. กลุ่มเว็บ — เลือก ทั้งหมด (เห็นเฉพาะกลุ่มที่มีสิทธิ์)
  6. แหล่งข้อมูล (src_path) — เลือกทั้ง โปรไฟล์ลูกค้า + กติกา/ตั้งค่าเว็บ
  7. กด บันทึก · ถ้าใส่ชื่อตัวแปรผิด ตอนเซฟระบบจะเตือนเรื่องค่า var
